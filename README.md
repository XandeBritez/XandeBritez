## Sobre mim

Desenvolvedor focado em transformar processos manuais em software simples de usar. Construo **aplicativos desktop nativos para Windows**, **apps Android** e **aplicações web em tempo real**, sempre com atenção a arquitetura limpa, testes e uma experiência que não precise de manual.

- 🖥️ **Desktop:** C# / .NET com WPF e WinUI 3, padrão MVVM, P/Invoke e automação (RPA)
- 📱 **Mobile:** Kotlin + Jetpack Compose, com regras de negócio isoladas em módulos puros e testáveis
- 🌐 **Web:** TypeScript, Next.js e NestJS com Socket.IO, além de APIs em Python / FastAPI
- 🗄️ **Dados & infra:** PostgreSQL, Redis, Prisma e Docker
- 🎯 **Princípio:** offline quando possível, privado por padrão, e o usuário final nunca precisa saber o que acontece por baixo
